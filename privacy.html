Gizlilik Politikası / Privacy Policy

Son güncelleme / Last updated: 31.10.2026

Türkçe

  • sosyal-dikey yalnızca uygulamanın sahibinin kendi hesapları için kullanılır.
  • Yalnızca okuma izinleri istenir: YouTube Analytics ve YouTube Data API salt okuma kapsamları; Instagram instagram_business_basic ve instagram_business_manage_insights; TikTok user.info.basic, user.info.stats ve video.list. Uygulama hesapta paylaşım yapamaz, içerik değiştiremez veya silemez.
  • Okunan veriler (video başlıkları, izlenme, beğeni, yorum sayısı, abone sayısı gibi istatistikler) yalnızca sahibin kendi bilgisayarındaki yerel bir veritabanında saklanır.
  • Veriler hiçbir üçüncü tarafla paylaşılmaz, satılmaz ve reklam amacıyla kullanılmaz.
  • Erişim belirteçleri (token) yalnızca yerel bilgisayarda, korumalı bir klasörde tutulur. İzin, Google hesabınızın Üçüncü taraf erişimi sayfasından istendiği an geri alınabilir. Instagram ve TikTok erişimi, her uygulamanın güvenlik / bağlı uygulamalar ayarlarından kaldırılabilir.
  • Uygulamanın Google API'lerinden aldığı bilgilerin kullanımı, Sınırlı Kullanım şartları dahil Google API Hizmetleri Kullanıcı Verileri Politikası'na uyar.

English

  • sosyal-dikey is used only for the owner's own accounts.
  • Only read-only scopes are requested: YouTube Analytics and YouTube Data API read-only scopes; Instagram instagram_business_basic and instagram_business_manage_insights; TikTok user.info.basic, user.info.stats and video.list. The app cannot post, modify or delete anything.
  • Data read (video titles and statistics such as views, likes, comments and subscriber counts) is stored only in a local database on the owner's own computer.
  • Data is never shared with or sold to third parties and is not used for advertising.
  • Access tokens are stored only on the local computer in a protected folder. Access can be revoked at any time at Google Account third-party access. Instagram and TikTok access can be removed from each app's security / connected apps settings.
  • The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
